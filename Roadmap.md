Release acceptance: deliver source, install instructions, design, contracts, test evidence and limitations together. No arbitrary calendar promise substitutes for real verification.

## Creator publication update · 2026-11-17

Implemented structured editorial brief/plan, scene roles and local viewer disclosures;
independent thumbnail/opening/closing in both render paths; creator-default UI, cover
editing/download, pre-TTS publication policy and current-hash content/cover review gates.
Compatibility drafts are explicitly limited to supplied content. Verified by 115 backend tests, 7 browser flows, TypeScript/build and fixed authored media checks; see verification-creator.json.
No new Ming video, native model quality, real TTS or isolated deployment acceptance is claimed.
Vertical/square composition, platform presets and advanced thumbnail art direction remain planned.


## Content positioning and taxonomy · 2026-11-18

Implemented independent purpose/subject/audience/forms, six primary audience tasks, optional
secondary purposes, exact legacy knowledge migration, resolved narrative strategy and typed
scene coverage, purpose-specific review, Studio creation/target editing and shared API catalog.
Verified by 143 backend tests, 8 browser flows, typecheck/build, six authored strategy samples
and the fixed creator renderer. Structural validation is separate from real native quality.
Real generated samples across all six purposes remain deployment acceptance.

Review follow-up: moved typed/domain/publication validation into bounded native retries,
rejected conflicting duplicate editorial plans, invalidated stale title/language/mode plans
and exposed pending request changes without reusing the old strategy display. Verification
details are recorded in goals/2026-11-18-content-taxonomy.md.

## Concrete object/action scenes · 2026-11-18

Implemented composable object silhouettes/ports, cables and distinct video/audio/control/data
signals, persistent device state, measured anchors, quiet original optional Foley, native
planning/review, Studio inspection/editing and shared protected rendering. Fixed nine-second
checks exercise both render paths and eleven prototype shapes; see verification-object-scenes.json.
HDMI revision reuses actual Edge narration/timing. Real native automatic asset generation,
unseen-object quality, text-to-image/video adapters, broad camera/3D systems and human full
watching/listening remain separate acceptance work. See goals/2026-11-18-object-scenes.md.

## Semantic visual production · 2026-11-18

Implemented typed semantic entities/state events/expectations, twelve trusted AI components,
device-screen bindings, structured shot intents, mediated original SVG/companion-PNG assets,
receipts/recovery/byte checks, shared scene renderer, dependency manifests, causal preview
coverage and Studio editing. Validation evidence is recorded in the semantic implementation
goal and docs/verification-semantic-scenes.json after actual checks.

Remaining V5 work: real native unseen-topic acceptance, external image/video/3D adapters,
general layer graphs and FFmpeg media backend, rendered-scene cache, advanced layout/OCR
review and human full playback/listening. Dependency keys are not a rendered-video cache.
