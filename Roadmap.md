# Roadmap

The product is an engineering video Agent, with Codex/Claude Code as replaceable native reasoning engines. Status distinguishes code implementation, fixture verification and real infrastructure acceptance.

| Milestone | Deliverables | Status |
|---|---|---|
| V2.1 baseline | Projects, revisions, source ingestion, Qwen adapter, alignment, template renderer, native CLI design adapter | Existing; 54 backend / 4 browser tests recorded |
| V3 engineering core | Production plan, script/motion specification, real TSX project generation, bounded observe/repair loop, source-hash gates | Implemented; fixture verification completed, see verification-v3.json |
| V3 quality and delivery | Required fonts, professional Qwen policy, keyframes, structured review, complete source ZIP, visible provenance | Implemented; fixture verification completed, see verification-v3.json |
| V3 deployment acceptance | Real Codex and Claude inference, Docker/gVisor generated-code execution, cancellation during real inference, sample quality review | Requires target infrastructure and credentials |
| Further capability | Managed Skill/MCP registry, advanced browser exploration, per-user credentials, collaborative approvals, larger visual evaluation sets | Planned; no completion claim |

Release acceptance: deliver source, install instructions, design, contracts, test evidence and limitations together. No arbitrary calendar promise substitutes for real verification.
