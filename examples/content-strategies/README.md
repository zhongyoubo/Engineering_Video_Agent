# Six authored editorial strategy examples

Each JSON file contains a creative Brief, a resolved EditorialPlan and ordered scene data.
The six examples illustrate different audience goals and narrative functions. They are
hand-authored contract fixtures, not native model responses, TTS samples or executed demos.

Validate with `.venv/bin/python scripts/verify_content_taxonomy.py`.
See `docs/product/positioning-and-content-taxonomy.md` for the classification and
`docs/design/content-strategy.md` for pipeline constraints and revision behavior.
