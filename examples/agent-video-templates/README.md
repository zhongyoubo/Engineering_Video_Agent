# AI Agent 科普视觉设计包

打开 [index.html](index.html) 查看交互式 HTML 风格手册。页面提供两套设计包、六种可选场景组件、可改标题/重点词/说明、16:9 / 1:1 / 9:16 画幅预览、字幕规范和 150 帧动效时间轴。`template-studio.css` 与 `template-studio.js` 是工作台源文件；工作台展示设计示意，不输出视频。

页面底部的“图标与动效”提供两套各六枚的可编辑 SVG 图标，以及“行动与反馈”“组成逐项揭示”“同题对比”三个一键播放入口。图标在本地 HTML 中内嵌绘制，下载的 SVG 源文件位于各设计包的 `assets/icon-set.svg`。时间轴按帧计算透明度、位移与箭头展开，可拖动检查任意时刻。

这里有两套独立的风格、素材与配色规范，分别取自“什么是 AI Agent？”和“一个 Agent 包含什么？”的画面。它们是可复用的视觉设计系统，可用于系列视频、封面或图文。

| 设计包 | 风格 | 适合内容 | 核心文件 |
|---|---|---|---|
| [深青编辑风格](dark-editorial/style-guide.md) | 深色、克制、明确的重点色 | 概念定义、比较、流程转变 | `dark-editorial/tokens.json`、`variables.css`、`assets/*.svg` |
| [暖白插画风格](warm-illustrated/style-guide.md) | 浅色、温暖、原创线条图标 | 组成部分、类别、步骤 | `warm-illustrated/tokens.json`、`variables.css`、`assets/icon-set.svg` |

两套设计包都包含 1920×1080 的安全区、字体层级、颜色、圆角与动效节奏。底部预留字幕区域。字体采用项目已有的 Noto Sans CJK SC Regular，许可见 `assets/fonts/LICENSE.txt`。SVG 素材为此模板原创，可编辑和重着色。

## 场景组件

| 组件 | 画面任务 | 主要视觉关系 |
|---|---|---|
| 概念定义 | 一句话说明对象 | 重点词 + 可识别对象 |
| 生活类比 | 用熟悉经验解释一层关系 | 熟悉事物 → 新概念，并说明类比边界 |
| 组成拆解 | 展示部件和职责 | 同层并列；有依赖时改用连线 |
| 过程与结果 | 解释操作如何产生结果 | 前态 → 动作 → 后态 |
| 概念对比 | 在同一任务上比较两种方式 | 共同问题 + 并列行为/结果 |
| 回顾与行动 | 留下一个可用结论 | 结论 + 下一步 |

场景按表达目标和内容关系选择，不按主题词自动路由。示例文字和图标可以替换；需要真实产品界面、测量或操作结果时，应使用有来源的素材。动效预览基于 30 fps、150 帧的设计节奏，字幕与真实配音需要在实际项目中重新对齐。

`DarkEditorial.tsx`、`WarmIllustrated.tsx` 和 `demo-Video.tsx` 提供可编辑的 Remotion 源码。`index.html` 提供交互设计预览。制作视频时将所需组件纳入工程，由隔离 Worker 构建和渲染。原 `render-previews.mjs` 命令会提示迁移入口后退出。
