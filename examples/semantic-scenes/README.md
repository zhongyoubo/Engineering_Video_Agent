# Fixed semantic scene examples

scenes.json contains authored Agent, RAG and twelve-component gallery data. It is not a
native model response. The fixture creates an original document SVG and companion PNG,
shows causal changes and binds goal/confirmation UI to laptop/phone screens.

Video.tsx is a fixed repository-owned verification dispatcher; it must never be replaced
with arbitrary user/generated source for host execution. Production authored source still
uses existing isolation and exact-hash acceptance.

Run `CHROME_EXECUTABLE=/path/to/chrome PYTHONPATH=apps/api/src .venv/bin/python scripts/verify_semantic_scenes.py`.
The check renders 1080p engineering and native-4K compatibility media, causal preview windows
and before/after samples. Estimates are draft-only; no native inference, TTS, real business
operation or full listening acceptance is claimed. See docs/design/semantic-production.md.
