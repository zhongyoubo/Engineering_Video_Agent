# Content-driven creative production

## Scope and baseline

User requires the engineering Agent to create appropriate assets/scenes/motion for a new
subject. Fixed city/matrix/network samples are vocabulary verification, not that acceptance.
Baseline: 0d1583e; 268 backend and 14 browser tests passed on that exact tree.

Implement a free-subject creation contract, independent narration-bound motion, source/image
bindings, general 3D activation, native planning/repair/review and reusable source-asset manifest.
Keep native authoring and the credential-free offline renderer. Existing image gateway/imports
remain available; no conversation image tool, keyword topic router or arbitrary host executor.

## Acceptance

- scripts/check.py, configured test:ui, format:check; preserve existing assertions.
- New native planning requires a specific visual goal/composition/subject/material/motion plan.
- Custom scene/source assets are validated, hashed, exported and reviewed; registered images
  are declared and consumed even without semantic-scene wrappers.
- Custom motions compile from actual narration, retain a held result frame and enter causal
  still/continuous review. Custom Three scenes enable software WebGL without SpatialCity.
- Real native unseen-topic production is deployment acceptance; missing credentials/Docker
  must remain an explicit block, never a fixed-fixture success claim.

## Progress

- Reproduced plan-wide grid/fan instructions and built-in-only WebGL activation.
- Added Scene.creation with free visual goals, composition, palette, subject/material/source
  descriptions and arbitrary target/channel before/change/after events. No fixed topic types.
- New native plans require creation per shot inside bounded repair; saved historical plans
  remain loadable. Legacy grid/fan limits are scoped, wrappers conditional, actual current
  revision designs are supplied explicitly to the authoring loop.
- Added measured custom motion compilation/budgets/held result frames, free progress helper,
  late-event still and continuous coverage, general Three software-WebGL selection and its
  required Docker COPY dependency.
- Source materials must be real tracked authored bytes; PNGs use normal declarations/receipts
  even without semantic wrappers. Build evidence and creative-manifest.json export source
  hashes/design/bindings/motion; parent checkpoints retain source modules for reuse.
- Native review must cover every created element/event and score subject fidelity, composition
  and causal motion. Generic positive review scores cannot bypass these gates. Studio shows
  the design without executing authored source. Creation changes clear stale compiled events.
- Updated README, Roadmap, AGENTS, authoring/template docs, schemas, API discovery and the
  material catalog (34 entries, new entry asserted). No baseline test was deleted/skipped or
  weakened; successful protocol fixtures gained the new required creation contract.

  pure contracts, TypeScript projects and Studio production build passed.
- Configured `npm run test:ui`: **15 passed** (1.4m), including design visibility/persistence
  and protection against executing authored source in Studio. Existing flows remain intact.
- `npm run format:check`, verifier-specific Ruff/Prettier and `git diff --check`: passed.
- Real `verify_engineering_deployment.py --provider codex --draft --creative --topic <new topic>`

  It did not invoke a model, bill a provider, render generated code on host or fabricate success.
- Current evidence: docs/verification-creative-production.json with source hashes and actual
  preflight flags. No new fixed sample is offered as proof of native creative quality.

## Remaining acceptance

Configured native new-topic creation and actual isolated rendering must demonstrate the
recognizable material/scene/motion quality. Professional voice/alignment and human full
watching/listening are still separate. Code modules are reusable project source; automatic
promotion to a global executable material library is not implemented. Existing image services
need their actual configured gateway. This increment implements the engineering contract and
enforcement, not a certified universal creative director or a new image/3D model.
