# 使用指南

## 提示词创作

选择「一个想法」，标题描述主题，文本说明受众、重点和实例。默认本地模板只组织你输入的内容，未配置模型时不会凭空声称已进行深入研究。需要更丰富的任意主题讲解，按部署文档配置模型。

先生成分镜可以快速编辑，不必等待配音和视频渲染。创建后页面轮询显示阶段；关闭浏览器不会取消后台任务。

## 源码创作

选择 ZIP，上传源码、README 和配置。默认 25MiB，展开最多 100MiB、5000 个文件。依赖目录、密钥文件、大文件和二进制会跳过。未知语言仍可提供文本和目录讲解，不能自动获得运行验证。

示例输入：`examples/source-demo.zip`。在证据页展开 `sync_demo.py` 可看到实际代码摘录。

## 分镜编辑

选择底部场景卡，编辑标题、类型、旁白、要点与代码展示。点击「仅保存脚本分镜」创建草稿版本；「保存为新版并导出」运行完整制作。已完成版本不会被覆盖。

锁定场景后不能改写。解锁需要单独保存一次，然后才能在新版本中修改。修改旁白会使该场景音频失效，未变化的旁白可复用。

## 一句话修改

本地支持“标题改为…”、“旁白改为…”。更自由的修改依赖配置的大模型；不理解的指令会返回说明，不会假装完成。修改当前场景并创建分镜新版本，确认后再导出。

## 更新源码

源码项目顶部点击「更新源码」，选择新 ZIP。系统重新建立证据与场景，音频缓存可复用相同旁白。当前不是精确符号级影响分析；新证据可能导致整体分镜重新规划，不承诺所有视觉场景保持原样。

## 实际运行

在创建页面的隔离设置中选择 static-web 或 python-cli，填写归档中的相对路径。仅当运维启用隔离环境时执行。静态 Web 支持页面加载、录像和最多三个明确标记 `data-demo-action="click"` 的按钮；不是任意 UI 自动探索。

如果真实演示为必选但环境不足，最终任务为 PARTIAL，报告说明未满足目标。可运行素材只说明本次环境观察，不等于生产性能保证。

## 导出与导入

视频下方提供 MP4、Markdown 脚本、SRT、质量报告、工程 ZIP。工程包含 JSON、音频和允许的媒体，不包含原始源码与环境密钥。

在「视频与版本」点击「导入可编辑工程」。导入执行路径、Schema、媒体 hash 和文件头检查。原始运行标记降为概念素材，导入文件不能证明新的可信运行。

## 声音和时长

eSpeak 是可直接使用的开发音色。专业男声需部署 Qwen 服务并先试听参考音色。选择「字幕版」允许无音轨导出；自动声音不可用时状态会提示部分完成。

目标时长是预算，不截断旁白。缩短视频优先精简旁白再导出。字幕时间为近似，正式汇报建议审片核对断句和同步。
