# ADR-0002：明确降级，模板优先

状态：接受。

决策：不配置模型时采用确定性基础脚本；配置后才调用模型。模型不得生成任意执行命令、资产 ID 或运行验证结论。内容引用经校验，错误输出退回模板并记录。

展示层采用可编辑 IR 与标准 React 场景，不把任意用户 TSX 当视频工程执行。源码运行只能经显式开启的受控容器适配器；源码静态分析和真实观察分别标识。

声音默认 eSpeak 开发音色或字幕，专业音色由独立 Qwen 模型服务提供。缺少声音/必选真实演示时不能伪称完整满足。

字幕句级估时和目标时长不等同于精确对齐/硬限制求解。质量报告必须写明。

理由：本地可直接验证完整媒体链路，降低部署成本，同时不以虚构模型结果、模拟运行或静音替代应有能力。
