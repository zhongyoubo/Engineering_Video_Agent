# V2.1 实现与验证范围

本表描述实际代码与证据。原始设计中的远期扩展并未全部变成已验证能力。

| 能力 | 实现与实测 |
|---|---|
| 提示词、ZIP、证据引用、脚本分镜、版本编辑、工程导入导出 | 已实现；后端与浏览器测试 |
| 公开 Git 导入与固定提交溯源 | 已实现；受控 HTTPS 主机、无凭据、不执行钩子；本次未接远端仓库验收 |
| 静态网页、Python CLI/API、Node、Vue/Vite、React/Vite 运行 | 已实现；六类自编可信示例实测通过；生产路径强制容器 |
| 交互动作、API 请求、界面结果断言 | 已实现；点击后文本断言、API 200 实测 |
| Qwen3-TTS 男声、本地离线模型推理 | 已实际加载 0.6B Base、参考音色并通过 HTTP 生成；推理子进程由内核禁止 IP 网络 |
| 字幕逐词时标 | eSpeak 原生事件或 stable-ts 已知文本强制对齐；真实音频实测；估时模式仍明确标记 |
| exact/max 时长策略 | 整数帧分配、有限语速调整、锁定冲突明确失败；不截旁白 |
| MP4、完整 WAV、SRT、脚本、对齐报告、质量报告、可编辑工程 | 已实现；真实媒体生成与解码 |
| Temporal 每阶段 Activity 与检查点 | 真实 Temporal Server 1.32.0 通过九次分阶段 Activity、重复调度和实际渲染 |
| PostgreSQL / S3 多 Worker 存储 | 原生 psycopg/boto3 实现；PGlite PostgreSQL 协议引擎与独立 Moto S3 HTTP 服务实测；尚不能替代原生 PG 并发和真实 S3 验收 |
| Docker/gVisor 隔离 | 生产执行路径已实现 fail-closed；当前环境无 Docker，未构建镜像或实际验证容器隔离 |
| 外部大模型脚本生成 | 适配器已实现，协议测试；本次未调用付费外部模型 |
| 私有仓库、任意依赖自动修复、移动/桌面/硬件、SSO/组织 RBAC/计费 | 尚未实现，不宣称全行业任意项目零配置可运行 |

任意可读源码可以静态解释；真实运行取决于受支持框架、入口、离线依赖和隔离环境。未知运行环境必须明确失败或仅静态讲解，不能伪造页面和运行成功。
