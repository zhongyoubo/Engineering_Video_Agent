# 安全设计与部署边界

## 信任边界

源归档、README、提示词、生成代码、导入媒体都不可信。模型不能设置执行命令、媒体 URL、已验证状态或任意素材 ID。Web API 与用户源码执行分开；默认禁用源码执行。

## 已实现措施

1. 上传大小、展开大小、文件数、压缩比、重复路径、加密、路径穿越和链接检查。
2. 跳过环境文件、常见凭证配置和依赖，字符串秘密做尽力脱敏；保留可解析的引号结构。
3. Cookie HttpOnly/SameSite、修改请求 Origin 校验、显式访问密钥。
4. 所有项目、输入、版本、任务、事件、素材授权都派生自服务端租户，不信任请求 tenant 参数。
5. 资源不可猜测 ID 加授权；404 避免暴露其他租户资源。内容去重不跨租户。
6. 模型输出经过 Pydantic Schema、引用、素材和验证状态检查；失败返回模板并记录降级。
7. 本地进程参数数组，无 shell 拼接；输出、时长、取消和清理有限制。
8. Docker 适配器无网络、源只读、限制 CPU/内存/PID、默认 runsc，并在 finally 显式删除容器。
9. 生成组件来自本应用模板，不执行用户上传 TSX。导入工程是 IR，不是任意 Remotion 渲染服务。
10. 外部模型和语音服务地址只允许部署配置，不允许用户提示词指定；HTTP 客户端不跟随重定向。

## 重要限制

这是本地/受控网络使用的应用，不是已经完成互联网渗透测试的 SaaS。工作空间密钥不能替代用户身份、权限审批、SSO、IP 限流和登录防爆破。公网部署前必须增加反向代理请求体限制、速率限制、TLS、组织身份与密钥轮换。

应用中的秘密检测是尽力过滤，不保证识别所有自定义凭证。原始归档按本租户保存，可能仍含用户自己的敏感内容；导出的视频可能展示用户主动保留的内容，发布前审片。不要上传生产密钥。

容器适配器提供受控机制，但是否构成所需隔离依赖 Docker/gVisor 配置、镜像和补丁。本环境未验证容器执行，不应未经验收直接开放给陌生互联网用户。

## 数据保留

本版不自动删除输入和对象。部署者负责备份、磁盘配额与保留策略。清理需要从资产引用计算，不能用文件年龄直接删除被历史版本使用的音频。Cookie 默认一天，HTTPS 部署启用 Secure。

## 生成与渲染

Remotion 的 publicDir 只包含已授权的 WAV/PNG/WebM 与字体。模型文本作为 React 文本，不使用 dangerouslySetInnerHTML。源网页只在隔离浏览器执行。资产下载加 nosniff，不将上传 HTML 在控制台同源内预览。
