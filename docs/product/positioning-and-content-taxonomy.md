# 产品定位与内容分类

版本：1.0 · 2026-11-18

## 产品定位

Engineering Video Agent 面向知识与技术内容创作者，把主题、资料或项目源码，
转化为有清晰主线、依据、解释和观众收益的视频。知识与技术内容是首个重点场景；
内容模型也可用于其他领域，但事实来源、素材与领域质量需要分别验证。

用户价值：帮助观众知道一个事物、理解一个道理、评估一个对象、思考一个观点、
做出一个选择或完成一种做法。工程能力继续承担编写 Remotion、合成语音、时间轴、
构建、观察和修复等工作。项目保留 Engineering_Video_Agent 仓库名与原生 Agent
工程路线，产品范围扩展不等于放松隔离、权限、证据和媒体质量约束。

## 四个独立维度

| 维度 | 回答什么 | 选择 |
|---|---|---|
| 表达目的 | 希望观众获得什么 | 介绍告知、解释理解、分析评估、观点论证、建议决策、教学操作 |
| 讲述对象 | 讲什么 | 项目、产品、技术、知识点、概念、原理机制、方法、流程、问题、现象 |
| 目标观众 | 为谁讲、讲到多深 | 保留现有观众类别，增加具体描述及入门/进阶/深入层次 |
| 表现形式 | 怎样帮助理解 | 图解动画、案例、对比、实操、代码讲解、数据展示、故事叙述 |

一条视频选择一个主要目的，允许最多两个辅助目的；辅助目的为主线服务。
讲述对象与表达目的自由组合。例如，同一个项目可用于介绍、原理解释、设计评估、
观点论证、选型建议或操作教学。“知识分享”是广义内容方向，具体每条视频仍需明确目的。
图解、录屏和代码属于表现形式，不能用它们替代观众收益。

创作请求保留核心主张和观众收益：分类决定主要任务，主张说明具体想讲什么，
收益说明观众看完能理解、判断或做什么。明确的用户选择优先于模型推断。

## 六类目的及质量标准

| 目的 / 标识 | 观众问题 | 建议结构 | 主要验收 |
|---|---|---|---|
| 介绍告知 / introduction | 它是什么、有什么值得知道的信息 | 对象与情境 → 关键事实 → 用途 → 回顾 | 事实清楚、有来源、有重点，避免照读完整功能清单 |
| 解释理解 / explanation | 为什么会这样、怎样运作 | 问题 → 对象/定义 → 关系/变化 → 例子 → 理解回顾 | 能解释对象、关系或机制；类比不掩盖边界 |
| 分析评估 / analysis | 价值、设计、取舍与适用条件是什么 | 问题 → 维度与依据 → 比较/拆解 → 限制 → 结论 | 有分析维度和依据，事实、推断与实测区分 |
| 观点论证 / viewpoint | 判断是什么、为什么值得相信 | 主张 → 证据与理由 → 其他解释/边界 → 回到主张 | 有支持、有回应或条件，不能只有立场 |
| 建议决策 / advice | 在什么条件下怎样选择和行动 | 需求 → 判断依据 → 条件与选择 → 下一步 → 收束 | 建议有条件、有依据，下一步可执行 |
| 教学操作 / tutorial | 需要什么、怎么完成、怎样判断成功 | 前提 → 步骤 → 示例 → 完成检查 → 回顾 | 前提、步骤与结果检查清楚；不能把示意包装成实操成功 |

这些结构是叙事建议。Agent 可以根据主题合并环节、增加案例、自由编写镜头与 TSX。
一个叙事环节可以包含多个实际场景，不要求每段都画成卡片，也不要求每类使用固定皮肤。

## 一个项目的不同选题

以 Ming TTS 为对象，可以提出六种不同任务：

- 介绍：认识这个项目及其用途。
- 解释：讲清语音合成中的文本、声音条件与生成过程。
- 分析：按视频配音需求评估项目能力与待验证项。
- 观点：论证“配音选型应优先关注什么”。
- 建议：给创作者一套使用自己文稿试听、决定是否接入的方法。
- 教学：依据实际环境和官方用法，完成一次部署/调用并说明检查方法。

这是选题矩阵，不代表本仓库已执行这些模型、部署和音质测试。示例原理和能力必须
使用实际资料核对；需要实操的片段应有运行证据，无法执行时只能保持示意身份。

## 自动策划与创作者控制

1. 用户输入主题/资料，可以选择目的，也可以选择 auto。
2. Agent 结合完整观众问题、材料、核心主张和收益解析 auto，并记录选择理由。
3. 输出主要目的、辅助目的、对象、观众、深度、表现形式、叙事结构和验收目标。
4. 为叙事环节关联实际场景，继续生成脚本、视觉设计和工程。
5. 结构校验、实际画面审查和内容目的审查通过后交付。

没有模型时，兼容路径仅编排已提供的内容，明确记录为待策划草稿。
不通过关键词猜测类型，不把输入是源码自动等同于“项目介绍”，也不声称兼容草稿
已完成六类内容创作质量验收。分类不需要额外独立 Agent 服务，可由现有原生 Agent 一次策划完成。

版本修改、Schema/API、六份不同叙事样例和自动回归。分类不会作为片内常驻标牌。

未宣称：每种类型的真实模型输出都达到创作者成片质量、完整观看试听或自动达到平台
传播效果。竖屏、方形、平台发布、复杂非线性剪辑与更多素材适配仍是后续工作。
