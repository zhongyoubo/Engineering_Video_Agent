# AI Agent 科普视觉模板 HTML 手册

`examples/agent-video-templates/index.html` 是可复用的静态设计手册，不是成片或自动选题器。它展示深青编辑、暖白插画两套独立风格，并把配色、字体、版式、SVG 素材、字幕和动效节奏放在同一页面。

场景工作台提供概念定义、生活类比、组成拆解、过程与结果、概念对比、回顾与行动六种表达任务。创作者可改标题、重点词和说明，切换 16:9 / 1:1 / 9:16 画幅，拖动或播放 30 fps / 150 帧的设计时间轴。选择按叙事关系人工进行；这不是主题关键词路由，也不会替代原生 Agent 的语义策划。

实现保持为静态 HTML/CSS/JS 和可编辑 SVG。`template-studio.js` 中的示例文案是示意，预览不执行用户代码，也不调用模型或渲染服务。画幅缩放是视觉排版预览，实际输出仍需按目标分辨率、真实素材、配音时长、字幕对齐和项目渲染检查。素材许可和字体来源见设计包 README。HTML 包包含页面、设计包源文件和本地字体。

两套设计包各提供六枚 SVG 图标。HTML 工作台将路径内嵌绘制，避免本地 `file://` 对跨文件 SVG `<use>` 的限制；各包仍保留可编辑的 `assets/icon-set.svg`。时间轴以帧决定图标和对象的位移、透明度、箭头展开及结果显现；三个动效卡片可以直接选择场景并播放。它们是交互式设计样机，尚未绑定真实旁白或生成可交付视频。

浏览器检查覆盖两套切换、每套六个图标可见、场景文案编辑、竖屏切换、帧 20/70 的不同可见状态、一键播放帧推进和 390 px 宽度无横向溢出；页面无 JavaScript 错误。该检查仅证明本地设计预览可操作，不证明视频的播放、听感或自动生成质量。
