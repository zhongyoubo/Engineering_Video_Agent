# phosphor curated adaptation

Source: https://github.com/phosphor-icons/core
Pinned revision: 2b75f3ad12b420c9504ef05df8d2564a28f8500e
License: MIT. Complete upstream notice retained in LICENSE.txt.

Only enumerated files are included. No upstream executable entry point, remote font or
network loader runs in the application. Phosphor paths become parameterized React SVG.
PNG previews are bounded derivatives, never claimed as new image inference. Motion text
removes fixed backgrounds, terminal badges and endless bounce; uses bundled CJK font.
GLB keeps geometry and resizes embedded textures to 512px; original SHA is in
../upstream-sources.json. Microsoft model credit and license metadata are retained.
