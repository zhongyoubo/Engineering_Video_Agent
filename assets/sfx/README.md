# Original interaction cues

connect.wav, click.wav and notify.wav are deterministic, original additive-synthesis Foley authored for this project (48kHz mono PCM). No third-party recording or model voice. Same Apache-2.0 licence as the project. These stylize interactions; they are not physical HDMI signal sounds or hardware measurements. Play quietly under narration; export preserves narration.wav as speech-only. Generator: scripts/generate_interaction_sfx.py.
